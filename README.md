# A Change of Plans — ELPA21-Inspired Listening Practice

Storm Studio • Grades 9–12 • Listening

Interactive listening practice: students hear Coach Rivera explain an indoor soccer practice, then answer 10 multiple-choice questions (main idea, details, sequence, vocabulary in context).

- `index.html` — the practice page (recorded audio, play counter, speed control, instant or end-of-quiz feedback, score + reflection, teacher answer key)
- `coach-rivera.mp3` — read-aloud recording (1:28)

Original ELPA21-inspired classroom practice. Not an official test item.
Design reference: Oregon Department of Education, ELPA grades 9–12 specifications, Listening.
